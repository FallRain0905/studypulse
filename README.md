# StudyPulse · 个人全科复习工作台

面向个人备考与日常刷题的多学科复习平台，采用 **陶瓷浅色（Porcelain Daylight）** 与 **曜石炭黑 × 暖琥珀（Obsidian Graphite × Warm Amber）** 双主题设计，当前集成三大模块：

- **CET-4 大学英语四级真题**（79 套真题 · 3,931 题 · 472 段原声 MP3）
  - 59 套完整 8 段听力卷（短篇新闻 1–3 / 长对话 1–2 / 听力篇章 1–3）+ 11 套无听力卷 + 3 套阅读分类专项（12 篇仔细 / 7 篇长篇 / 6 篇选词）+ 6 套翻译汇编
  - 自动补全选词填空（支持单/双列 15 词库）、长篇匹配与仔细阅读原文
  - 125 分钟 710 分限时模考、120–180 词写作字数统计、HTTP 206 流式倍速听力与 710 分估分报告
- **CET-6 大学英语六级真题**（75 套真题 · 3,653 题 · 399 段原声 MP3）
  - 57 套完整 7 段听力卷 + 12 套无听力卷 + 6 套翻译汇编
  - 自动还原 69/69 套长篇阅读完整段落，支持 130 分钟 710 分模考与沉浸刷题模式
- **Python 程序设计课程复习**
  - 9 章完整教材精讲（47 节 + 33 例题）、146 道章节单选与错题本、22 个自动判题实训实验、40 张 3D 记忆闪卡
  - 内置 Web Python IDE（支持多文件运行、标准输入与本地 Python 3 实时执行）

---

## 技术栈

- **前端**：React 19 + TypeScript + Vite 8 + Tailwind CSS v4 + Lucide Icons
- **本地开发后端**：Vite 中间件（`vite-python-runner.ts`、`vite-cet6-server.ts`）
- **生产服务**：零依赖 Node.js HTTP 服务（`server.mjs`），支持静态资源托管、Python 3 沙箱执行、CET-4 / CET-6 预解析题库接口及 MP3 `Range`（HTTP `206 Partial Content`）流式拖拽

---

## 快速开始

### 1. 安装依赖与本地开发

```bash
npm install
npm run dev
```

默认访问地址：`http://127.0.0.1:5173/`。

Windows 用户也可直接双击根目录的一键脚本：
- `一键启动-PyPulse复习平台.bat` / `一键启动-无黑框版.vbs`：一键启动本地服务并打开浏览器
- `停止复习平台.bat`：停止后台本地服务

### 2. 生产构建与运行

```bash
npm run build
node server.mjs
```

`server.mjs` 支持通过环境变量配置路径与数据目录：

| 环境变量 | 说明 | 默认值 |
| --- | --- | --- |
| `HOST` | 监听地址 | `127.0.0.1` |
| `PORT` | 监听端口 | `3456` |
| `BASE_PREFIX` | 子路径前缀（根域名部署留空） | `""` |
| `CET4_DATA_DIR` | 预解析 CET-4 题库与音频目录 | `/opt/pypulse/cet4-data` |
| `CET6_DATA_DIR` | 预解析 CET-6 题库与音频目录 | `/opt/pypulse/cet6-data` |
| `PYTHON_BIN` | 服务器 Python 3 可执行文件路径 | `python3` |

> 注：四级与六级真题音频体量较大（共约 2.2 GB），不包含在 Git 仓库中，运行时由本地题库目录或服务器数据目录只读挂载。
